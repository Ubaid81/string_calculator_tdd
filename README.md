# String Calculator

A simple Dart command-line application that implements a string-based calculator.  

## Project Structure  
- **`bin/`** - Contains the entry point for running the application.  
- **`lib/`** - Contains the core logic for parsing and summing numbers from a string.  
- **`test/`** - Includes unit tests to ensure correctness following Test-Driven Development (TDD).  

## Features  
- Supports basic addition of numbers from a string input.  
- Handles different delimiters (`,`, `\n`, and custom delimiters using `//[delimeter]\n[number]` format).  
- Throws an error for negative numbers.  

## Running the Application  
```sh
dart run
```
